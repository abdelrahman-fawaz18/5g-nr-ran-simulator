# Changelog

All notable changes follow Semantic Versioning for the simulator package and evidence contracts.

## [0.1.0] - 2026-08-14

### System

- deterministic typed scenarios, semantic random streams, packet queues and integer-time events;
- 3GPP Release 18-informed propagation, link budget, FR1 resources, CQI/MCS and TBS models;
- Round Robin, Max-C/I and Proportional Fair scheduling with versioned QoS/KPI reducers;
- opt-in dynamic FR1 mobility/interference/handover and bounded FR2 beam/blockage profiles; and
- paired multi-seed orchestration, bootstrap analysis, immutable artifacts and evidence verification.

### Verification and presentation

- independent analytical, Decimal-oracle, property, regression and performance evidence;
- preregistered 360-run heterogeneous-QoS scheduler study with a compact verified snapshot;
- large-format accessible SVG architecture, trade-off, load-response and evidence visuals; and
- Windows/Linux × Python 3.11/3.13 continuous quality gates.

### Fidelity boundary

Model behavior is verified within documented domains but is not measurement-calibrated. The
release does not claim protocol conformance, commercial RF-planning accuracy or digital-twin
fidelity.
